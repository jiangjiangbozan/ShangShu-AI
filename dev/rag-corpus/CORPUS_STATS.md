# 尚枢 AI 知识库语料与切片统计

> 统计时间：2026-11-27 · 数据源：`ai_agent` 库（MySQL 8）+ `ai_agent_knowledge` 索引（Elasticsearch 9）
> 统计口径：仅统计 `deleted=0` 的有效记录，切片 token 数为分片入库时写入的 `token_count`

## 结论摘要

- 全库共 **62 篇文档 / 1,155 条切片 / 约 19.2 万 token**，覆盖项目自文档与三条主流技术栈的官方文档。
- **入库链路零丢失**：MySQL 切片数 1,155 与 ES 向量数 1,155 完全一致，说明「解析 → 切片 → 向量化 → 写索引」四步对账平衡。
- **切片粒度健康**：无空切片；有效切片长度 12–997 字符、均值 665 字符，平均 165–170 token，恰好落在 800 字符窗口 + 200 字符重叠的设计范围内。
- 在 50 题中文评测集上，全链路 **Recall@5 0.940 / MRR 0.845 / nDCG@5 0.870 / 命中率 94%**。

## 四、检索效果：向量模型切换前后（同一 50 题数据集、同一知识库）

| 阶段 | 指标 | 本地 nomic-embed-text（旧） | 百炼 qwen3.7-text-embedding-flash（新） | 变化 |
|---|---|---|---|---|
| 纯向量 | Recall@5 | 0.480 | **0.820** | +0.340 |
| 纯向量 | nDCG@5 | 0.383 | **0.731** | +0.348 |
| 向量+关键词+RRF | Recall@5 | 0.780 | **0.940** | +0.160 |
| 向量+关键词+RRF | nDCG@5 | 0.563 | **0.794** | +0.231 |
| +Rerank | Recall@5 | 0.820 | **0.940** | +0.120 |
| +Rerank | MRR | 0.745 | **0.845** | +0.100 |
| +Rerank | nDCG@5 | 0.764 | **0.870** | +0.106 |
| 全链路 | 命中率 | 82.0% | **94.0%** | +12 pt |

- 评测环境完全一致（同 50 题、topK=5、RRF k=60、rerank 走百炼原生协议），仅替换向量化后端，因此差值可直接归因于 embedding 质量。
- 纯向量召回率接近翻倍（0.480 → 0.820），说明中文语义匹配能力是旧本地模型的主要瓶颈。
- 延迟：服务端链路均值 13,262 ms（P50 12,751 / P95 18,374），与旧基线 13.6 s 基本持平——瓶颈在本地 Ollama 的 QueryRewrite，而非新增的百炼调用。

## 五、复现方式

```bash
# 1. 重嵌入现有分片（保留 chunk id，评测数据集不失效）
cd dev/rag-eval && python reembed.py --index ai_agent_knowledge

# 2. 批次 B 语料下载与入库
cd dev/rag-corpus && python download_corpus_b.py && python upload_corpus_b.py

# 3. 50 题评测
cd dev/rag-eval && python run_eval.py --kb-id 1 --output p1-results.json --report p1-embed-report.md
```

> 注：embedding 与 rerank 均走百炼，chat / QueryRewrite 仍用本地 Ollama，评测与研究不依赖外部付费额度。
