# 移动端（Android）阶段性测试计划

> 适用项目：`d:\ai\ai-agent-client`
> 目的：验证移动端与 Web 端功能一致性、数据同步正确性，以及移动端特有需求（屏幕适配、触控交互、离线处理）的实现质量。

## 测试环境

| 项目 | 要求 |
| --- | --- |
| JDK | 25（Android Studio 自带 JBR：`D:\JetBrains\Android Studio\jbr`） |
| 构建命令 | `$env:JAVA_HOME = "D:\JetBrains\Android Studio\jbr"; .\gradlew.bat :app:assembleDebug` |
| 后端服务 | `d:\ai\api` 启动于 `http://localhost:8080`（含 Redis/RabbitMQ/ES） |
| 真机/模拟器 | API 24–35，至少覆盖 1 台低分辨率 + 1 台高分辨率设备 |

---

## 阶段 0：构建与静态验证

**目标**：保证工程可编译、无阻塞性配置错误。

| 编号 | 测试项 | 步骤 | 通过标准 |

## 阶段 1：认证模块

**目标**：登录、注册、退出登录、令牌持久化与自动刷新闭环。

| 编号 | 测试项 | 步骤 | 通过标准 |
| --- | --- | --- | --- |
| 1.1 | 登录成功 | 正确账号密码 → 登录 | 进入主界面，Token 写入 DataStore |
| 1.2 | 登录失败 | 错误密码 → 登录 | 提示错误信息，不跳转 |
| 1.3 | 注册 | 新账号注册 → 自动/手动登录 | 注册成功后进入主界面或跳转登录 |
| 1.4 | 令牌持久化 | 登录后杀掉进程重开 | 无需重新登录，直达主界面 |
| 1.5 | 自动刷新 | 使用过期 AccessToken 请求 | 401 触发 refresh，请求自动重试成功 |
| 1.6 | 退出登录 | 「我的」页点击退出 | 清除 DataStore，回登录页 |

## 阶段 4：网络与离线处理

**目标**：网络异常 / 弱网 / 离线场景健壮性。

| 编号 | 测试项 | 步骤 | 通过标准 |
| --- | --- | --- | --- |
| 4.1 | 离线请求 | 断网发送消息 | 友好错误提示，不崩溃 |
| 4.2 | 弱网流式 | 限制带宽下发送 | 流式不断连（ReadTimeout=0 生效） |

## 退出准则

- 阶段 0–3 全部通过后方可进入阶段 4–6。
- 任一阶段存在 P0/P1 缺陷（崩溃、数据丢失、功能不可用）不得进入下一阶段。
- 阶段 6 通过后视为移动端 MVP 达成。
