# 知识库语料与切片统计

> 统计时间：2026-11-27 · 数据源：`ai_agent`（MySQL）+ `ai_agent_knowledge`（Elasticsearch）
> 口径：仅统计 `deleted=0` 的有效记录；切片 token 为分片入库时写入的 `token_count`

## 结论

- 全库 **227 篇文档 / 2,885 条切片 / 493,783 token**，覆盖项目自文档、四条技术栈官方文档与 Kubernetes 中文文档。
- **链路零丢失**：MySQL 切片数 2,885 与 ES 向量数 2,885 完全一致，「解析 → 切片 → 向量化 → 写索引」四步对账平衡。
- **切片粒度健康**：空切片 0；长度 12–997 字符、均值约 684 字符、平均 171 token，落在 `chunkSize=800` + `chunkOverlap=200` 的设计区间。
- 中文语料（kb5）实测：**纯向量 Recall@5 0.963、RRF 0.975、命中率 97.5%**，80 题全链路详见 `rag-eval-kb5-report.md`。

## 四、新增语料的流程

```bash
# 1. 抓取（增量抓取自动跳过已抓页面，可按分区筛选）
cd dev/rag-corpus && python fetch_k8s_zh.py --limit 60 --sections concepts

# 2. 入库（按名称复用知识库；--from-order 只传新增文件，避免重复入库）
python upload_corpus_c.py --from-order 146

# 3. 若更换了向量模型，按知识库定点重算历史分片向量
cd ../rag-eval && python reembed.py --kb-id 4

# 4. 对账：MySQL 切片数应等于 ES 向量数
curl "http://localhost:9200/ai_agent_knowledge/_count"
```
