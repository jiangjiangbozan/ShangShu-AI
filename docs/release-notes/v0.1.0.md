# v0.1.0 · 第一个可运行的完整版本

> 发布日期：2026-11-19 · [Release 页面](https://github.com/jiangjiangbozan/ShangShu-AI/releases/tag/v0.1.0)

尚枢 AI（ShangShu AI）第一个公开版本。面向 Java / Spring Boot 团队的自托管 AI 应用平台：基于 Spring AI，将企业知识库 RAG、可视化 Agent 工作流、动态模型管理与运行观测整合到 Java 技术栈中。

## 功能亮点

### AI 应用发布（四类型）

- 应用类型全覆盖：**Chat / RAG / Agent / Workflow**，创建后一键发布
- 统一调用网关 `POST /api/v1/app/{appKey}/chat`，兼容 OpenAI Chat Completions 协议
- 独立应用 API Key（哈希存储、可过期），支持多轮 messages 上下文

### 可视化工作流引擎（生产化加固）

- **20 种节点执行器**：LLM、IfElse、Loop、Iteration、KnowledgeRetrieval、QuestionClassifier、Agent、Code、HttpRequest、Tool、HumanInput、VariableAssigner、VariableAggregator、TemplateTransform、ParameterExtractor、ListFilter、DocExtractor、Answer、Start、End
- **SPI 式扩展**：第三方实现 `NodeExecutor` 接口 + AutoConfiguration 注册即可并入引擎，详见 `docs/workflow-node-spi.md`
- **DAG 分层并行执行**：Kahn 分层拓扑 + 虚拟线程 + Semaphore 限流（`workflow.parallelism`，默认 4）
- **变量系统**：`${nodeId.key}` 引用、`${global.*}` 全局作用域、`resolveTyped` 类型校验
- **节点级重试**：`retry.maxAttempts` / `retry.backoffMs` + `onError: fail|continue` 降级策略
- **版本化快照**：发布冻结 graph 为不可变版本，执行按快照回放
- **执行记录**：节点级状态 / 耗时 / 输入输出落库，前端按原始画布布局回放 DAG

### 企业级 RAG 检索链路

- QueryRewrite（主备模型降级）→ 向量 + BM25 关键词双路召回 → RRF 融合 → Rerank 精排 → 父文档 / 知识图谱扩展路
- 检索测试接口逐步展开全链路（每步输入输出与耗时）
- **50 题评测数据集与对比报告**（`docs/rag-eval-report.md`）：Recall@5 / MRR / nDCG@5 量化指标，评测套件可复现（`dev/rag-eval/`）

### 平台基础

- 多模型接入：DeepSeek / 通义 / Ollama 统一接入，动态加载、连通性测试、路由降级
- 安全体系：JWT 双 Token、CSRF Double-Submit、XSS Filter、RBAC、Jasypt 加密
- 可观测：TraceId 全链路、对话日志、LLM 调用统计、Prometheus 指标
- Prompt 版本管理、智能客服（意图识别 / 槽位填充 / 状态机）、课程知识问答

## 已知限制

- RAG 评测显示当前语料下 BM25 单路召回（Recall@5 0.80）优于向量单路（0.48），Rerank 在未配置 `RAG_RERANK_*` 时自动降级关闭
- Spring Boot 4.1.0 与 Spring AI 2.0.0 均已 GA 并固定版本；升级补丁版本前需通过兼容性验证，暂不盲目追新
- 多租户、工作流断点恢复、Human-in-the-loop 暂未实现（见 README Roadmap）

## 升级说明

首次安装请参照 [README 快速开始](../../README.md#快速开始)：`docker compose up -d` 启动中间件 → 后端 `mvn spring-boot:run`（dev 默认值已与 Compose 对齐，零配置可跑）/ 前端 `npm run dev`；完整部署用 `docker compose --profile full up -d --build`（需先复制 `.env.example` 为 `.env`）。
